## Layout

- Max content width: `1280px` (`--site-max`)
- Horizontal gutter: `clamp(20px, 4vw, 64px)` (`--site-gutter`)
- All major sections centered via `margin: 0 auto`

### Breakpoints

| Width | Change |
|---|---|
| ≤ 560px | Mobile — small tabs, tighter padding |
| ≤ 900px | Notebook collapses to single column, spine hidden |
| ≤ 1024px | Gallery nav switches to mobile dropdown |

## Sections

### Intro (`#intro`)
- Full-bleed image slideshow (images from `projects.json` cover images)
- Dot pagination auto-generated by JS
- Large `h1` text overlay: "梁芷穎 / Profolio"

### Skills (`#skills`)
- Notebook / scrapbook layout (`sk-book`) — two-column grid
- **Left page**: polaroid-style photo + typewriter bio animation
- **Right page**: tabbed skill chapters (前端 / 動畫 / 互動 / 平面)
- Each chapter has: kicker, title with tinted highlight underlay, tool list with animated bullets
- Entry animation: GSAP (`opacity 0→1`, `y 28→0`, `scale .985→1`, `expo.out`, 1.1s) triggered by ScrollTrigger at `top 82%`

### Recent Posts (`#posts-section`)
- Timeline layout, data from `posts.json`
- Compact view with expand button → full-screen modal
- Modal: keyboard ESC to close, `aria-modal` accessible

### Gallery (`#gallery`)
- Three categories: `installation` / `animation` / `painting`
- Desktop: horizontal nav tabs
- Mobile: dropdown selector
- Cards generated by JS from `projects.json`
- YouTube videos open in an overlay modal (`#videoModal`)

## Animation

Library: **GSAP 3.12.5** + **ScrollTrigger** (CDN)
Smooth scroll: **Lenis 1.0.29** (CDN)

### Principles
- Scroll-triggered, fires once (`once: true`)
- Respects `prefers-reduced-motion`: falls back to `no-anim` class (opacity: 1, no transform)
- `will-change: transform, opacity` set before animation, cleared on complete

### Key animations
| Element | Tween | Trigger |
|---|---|---|
| `.sk-book` | `y: 28→0, scale: .985→1, opacity: 0→1` (1.1s expo.out) | `top 82%` |
| `.skill-H2 h2` | CSS transition `opacity + translateY(16px)` (0.6s) | IntersectionObserver 15% |
| `sk-chapter` items | CSS `@keyframes skFade` (0.45s, staggered delays) | Tab click |
| Bio paragraphs | JS typewriter — 55ms/char, 280ms line gap | IntersectionObserver 25% |
